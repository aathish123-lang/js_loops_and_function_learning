# 🚀 JavaScript Practice Tasks

This repository contains **10 JavaScript practice problems** completed to strengthen my **JavaScript fundamentals and logical thinking**.

## 📚 Tasks Covered

1. **Add or Even** – Checks whether a number is even or odd. 
2. **Result Evaluator** – Checks whether marks are Pass or Fail and validates the marks. 
3. **Maximum Finder** – Finds the largest number among three numbers. 
4. **Accumulator** – Calculates the sum of numbers from 1 to N. 
5. **Multiplication Table Generator** – Prints the multiplication table from 1 to 10. 
6. **Digit Counter** – Counts the number of digits in a number using a loop. 
7. **Number Reverser** – Reverses the digits of a number using mathematical operations. 
8. **Factorial Engine** – Calculates the factorial of a number using a loop. 
9. **Prime Validator** – Checks whether a number is prime. 
10. **Pattern Builder** – Prints a star triangle pattern using nested loops.
